# 🧠 Sistema Preditivo de Score de Crédito

## 📌 Sobre o projeto
Desenvolvimento de um modelo de machine learning para prever a nota de crédito de clientes.

O projeto inclui todo o pipeline de dados, desde a limpeza até o treinamento e avaliação do modelo.

## 🚀 Tecnologias utilizadas
- Python
- Machine Learning
- Engenharia de dados

## 💡 Resultados
- Modelo com 86% de precisão
- Apoio à tomada de decisão em concessão de crédito
